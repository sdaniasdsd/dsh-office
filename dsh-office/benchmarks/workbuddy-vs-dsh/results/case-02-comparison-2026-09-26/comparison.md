# Case 02 comparison

| Runner | First pass | Final | Repairs | Failed gates | Regressions | Report status |
|---|---:|---:|---:|---|---|---|
| WorkBuddy | 99/100 | 99/100 | 0/2 | none | none | complete |
| DSH DOCX plugin | 90/100 | 90/100 | 0/2 | none | none | complete |

WorkBuddy wins this case. Both candidates completed the requested edit and rendered cleanly, but WorkBuddy anchored the new comment to the exact quoted sentence. The plugin anchored the same comment to the whole two-sentence paragraph. WorkBuddy also produced more granular tracked changes in the executive summary, which is easier to review and better contained.

This is a result for one fixed case and two supplied first-pass files. It does not establish that WorkBuddy is globally stronger across DOCX creation, layout redesign, damaged-file recovery, or repeated runs.
