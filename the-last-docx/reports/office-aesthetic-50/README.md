# Office aesthetic benchmark (50 cases)

This published report contains the frozen case contracts, per-case scorecards, operation/verifier records, and run summary.

The complete rendered evidence bundle (source and candidate files, every full-resolution page image, and contact sheets) remains in the local ignored path `dist/office-aesthetic-50/`. It is about 417 MB, so it is intentionally not added to the Git history. Each manifest/report points to the local evidence and records artifact/page checksums; a clone of this repository will not contain those screenshots unless the evidence bundle is separately transferred.

Run the same batch with `npx tsx scripts/office-aesthetic-50.mjs all` after restoring the frozen input corpus and DSH runtime. The per-case documents distinguish local evidence completeness from the subset of report metadata published here.
