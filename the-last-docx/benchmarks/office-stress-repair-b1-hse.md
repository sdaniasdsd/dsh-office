## Attention lock

Repair only the final checklist row in the frozen HSE asbestos-management plan so the row stays together across page boundaries. Preserve all text and unrelated document content. Do not change the frozen source, rewrite the whole document, or alter unrelated layout settings.

## Finding and engineering decision

The original 9-page LibreOffice render split the last checklist table row across pages 8 and 9, leaving a short continuation on page 9. The attempted paragraph-level `keepLines` hint was present in OOXML but did not change LibreOffice pagination, so it was discarded. The effective control is row-level WordprocessingML `w:cantSplit`.

Added an opt-in `rowPagination` property to `docx-edit` table formatting. It is zero-based, validates row indexes and duplicates, writes `w:cantSplit`, and verifies the saved value. Existing callers are unchanged unless they opt in. Batch script: `scripts/repair-batch-01-hse.mjs`.
